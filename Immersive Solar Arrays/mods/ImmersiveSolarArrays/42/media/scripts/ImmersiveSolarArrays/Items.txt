/*
    Build 42 item scripts.

    Field shapes were taken from vanilla's own generated item scripts, not carried over
    from the build 41 originals:

      ItemType = base:*     replaces "Type = ...". Build 42 does not parse "Type" at all,
                            so every item here used to load with a null item type.
      DisplayName           dropped. Names come from Translate/<LANG>/ItemName.json,
                            keyed by full type.
      LearnedRecipes        replaces "TeachedRecipes", which build 42 no longer parses.
      Tags                  namespaced. A bare "Generator" tag matches nothing, because
                            tag strings are compared literally after lowercasing.

    ISA_maxCapacity and ISA_BatteryDegrade are not engine fields. Unrecognised keys are
    parsed into the item's default modData, which is how the powerbank code reads them.
*/
